## 一、项目背景与目标

### 1.1 研究背景

传统网络鲁棒性研究假设节点失效是随机的（随机攻击）或基于度数（蓄意攻击）。然而在AI时代，攻击者本身就是智能体，会学习、欺骗、自适应地切断关键链路。这种智能体对智能体的攻防博弈，将彻底改写网络鲁棒性的定义。

### 1.2 核心目标

| 目标 | 描述 |
|------|------|
| 搭建任务协作网络 | 构建多智能体任务协作网络，设置防御方和攻击方 |
| 动态攻防博弈 | 攻击方自适应破坏网络链路/节点，防御方实时修复加固 |
| 鲁棒性量化分析 | 观测网络鲁棒性变化，对比传统攻击与AI自适应攻击差异 |
| 涌现现象研究 | 发现攻防博弈过程中的涌现行为与规律 |

### 1.3 预期成果

- 完整的攻防博弈实验系统
- 鲁棒性指标变化曲线图
- 动态网络攻防演示视频/GIF
- 对比分析报告

"""
大模型配置模块
支持本地Ollama + 在线API的灵活切换
"""

import os
from enum import Enum
from typing import Optional, Dict, Any

class ModelProvider(Enum):
    """支持的模型提供商"""
    OLLAMA_LOCAL = "ollama_local"      # 本地Ollama
    DASHSCOPE = "dashscope"            # 通义千问
    WENXIN = "wenxin"                  # 文心一言
    DEEPSEEK = "deepseek"              # DeepSeek

class ModelConfig:
    """模型配置管理"""
    
    def __init__(self):
        self.configs = {
            ModelProvider.OLLAMA_LOCAL: {
                "model_name": "qwen2.5:7b",
                "base_url": "http://localhost:11434",
                "api_key": "ollama",  # Ollama不需要真实key
                "temperature": 0.7,
                "max_tokens": 512,
                "enabled": True  # 默认启用本地模型
            },
            ModelProvider.DASHSCOPE: {
                "model_name": "qwen-plus",
                "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
                "api_key": os.getenv("DASHSCOPE_API_KEY", ""),
                "temperature": 0.7,
                "max_tokens": 1024,
                "enabled": bool(os.getenv("DASHSCOPE_API_KEY"))
            },
            ModelProvider.WENXIN: {
                "model_name": "ernie-4.0-8k-latest",
                "base_url": "https://aip.baidubce.com/rpc/2.0/ai_custom/v1",
                "api_key": os.getenv("WENXIN_API_KEY", ""),
                "secret_key": os.getenv("WENXIN_SECRET_KEY", ""),
                "temperature": 0.7,
                "max_tokens": 1024,
                "enabled": bool(os.getenv("WENXIN_API_KEY"))
            },
            ModelProvider.DEEPSEEK: {
                "model_name": "deepseek-chat",
                "base_url": "https://api.deepseek.com/v1",
                "api_key": os.getenv("DEEPSEEK_API_KEY", ""),
                "temperature": 0.7,
                "max_tokens": 1024,
                "enabled": bool(os.getenv("DEEPSEEK_API_KEY"))
            }
        }
    
    def get_config(self, provider: ModelProvider) -> Optional[Dict[str, Any]]:
        """获取指定provider的配置"""
        config = self.configs.get(provider)
        if config and config.get("enabled"):
            return config
        return None
    
    def get_available_providers(self) -> list:
        """获取所有可用的模型提供商"""
        return [p for p, c in self.configs.items() if c.get("enabled")]
    
    def get_primary_model(self) -> Optional[Dict[str, Any]]:
        """获取主模型（优先本地Ollama）"""
        ollama = self.get_config(ModelProvider.OLLAMA_LOCAL)
        if ollama:
            return {**ollama, "provider": ModelProvider.OLLAMA_LOCAL}
        
        # 依次尝试其他在线API
        for provider in [ModelProvider.DASHSCOPE, ModelProvider.DEEPSEEK, ModelProvider.WENXIN]:
            config = self.get_config(provider)
            if config:
                return {**config, "provider": provider}
        return None

# 全局配置实例
model_config = ModelConfig()

### 3.5 模型调用封装

**统一调用接口：core/model_manager.py**

```python
"""
统一模型调用接口
实现本地Ollama与在线API的无缝切换
"""

import logging
from abc import ABC, abstractmethod
from typing import List, Dict, Any, Optional
from openai import OpenAI
import ollama

from config.model_config import ModelProvider, ModelConfig, model_config

logger = logging.getLogger(__name__)


class BaseModelClient(ABC):
    """模型客户端基类"""
    
    @abstractmethod
    def chat(self, messages: List[Dict], **kwargs) -> str:
        """发送对话请求"""
        pass


class OllamaClient(BaseModelClient):
    """本地Ollama客户端"""
    
    def __init__(self, model_name: str = "qwen2.5:7b"):
        self.model_name = model_name
    
    def chat(self, messages: List[Dict], **kwargs) -> str:
        """通过Ollama API调用本地模型"""
        try:
            # 转换消息格式
            prompt = self._format_prompt(messages)
            
            response = ollama.chat(
                model=self.model_name,
                messages=[{"role": "user", "content": prompt}],
                options={
                    "temperature": kwargs.get("temperature", 0.7),
                    "num_predict": kwargs.get("max_tokens", 512)
                }
            )
            return response['message']['content']
        except Exception as e:
            logger.error(f"Ollama调用失败: {e}")
            return f"Error: {str(e)}"
    
    def _format_prompt(self, messages: List[Dict]) -> str:
        """将消息列表格式化为单个prompt"""
        prompt = ""
        for msg in messages:
            role = msg.get("role", "user")
            content = msg.get("content", "")
            prompt += f"{role}: {content}\n"
        return prompt


class OpenAICompatibleClient(BaseModelClient):
    """OpenAI兼容格式的API客户端"""
    
    def __init__(self, base_url: str, api_key: str, model_name: str, **kwargs):
        self.client = OpenAI(
            api_key=api_key,
            base_url=base_url
        )
        self.model_name = model_name
        self.default_params = kwargs
    
    def chat(self, messages: List[Dict], **kwargs) -> str:
        """通过OpenAI兼容API调用模型"""
        try:
            params = {**self.default_params, **kwargs}
            response = self.client.chat.completions.create(
                model=self.model_name,
                messages=messages,
                temperature=params.get("temperature", 0.7),
                max_tokens=params.get("max_tokens", 1024)
            )
            return response.choices[0].message.content
        except Exception as e:
            logger.error(f"API调用失败: {e}")
            return f"Error: {str(e)}"


class ModelManager:
    """模型管理器 - 统一调度"""
    
    def __init__(self):
        self.clients: Dict[ModelProvider, BaseModelClient] = {}
        self._init_clients()
    
    def _init_clients(self):
        """初始化所有可用的模型客户端"""
        config = model_config
        
        # 初始化Ollama本地模型
        ollama_conf = config.get_config(ModelProvider.OLLAMA_LOCAL)
        if ollama_conf:
            self.clients[ModelProvider.OLLAMA_LOCAL] = OllamaClient(
                model_name=ollama_conf["model_name"]
            )
        
        # 初始化在线API
        for provider in [ModelProvider.DASHSCOPE, ModelProvider.WENXIN, ModelProvider.DEEPSEEK]:
            conf = config.get_config(provider)
            if conf and "base_url" in conf:
                self.clients[provider] = OpenAICompatibleClient(
                    base_url=conf["base_url"],
                    api_key=conf["api_key"],
                    model_name=conf["model_name"],
                    temperature=conf["temperature"],
                    max_tokens=conf["max_tokens"]
                )
    
    def chat(self, messages: List[Dict], provider: Optional[ModelProvider] = None, **kwargs) -> str:
        """
        对话接口
        
        Args:
            messages: 消息列表
            provider: 指定模型提供商，None时自动选择
            **kwargs: 其他参数
            
        Returns:
            模型回复内容
        """
        if provider:
            client = self.clients.get(provider)
            if client:
                return client.chat(messages, **kwargs)
        
        # 自动选择：优先本地，次选在线
        for p in [ModelProvider.OLLAMA_LOCAL, ModelProvider.DASHSCOPE, 
                  ModelProvider.DEEPSEEK, ModelProvider.WENXIN]:
            client = self.clients.get(p)
            if client:
                logger.info(f"使用模型: {p.value}")
                return client.chat(messages, **kwargs)
        
        return "Error: No available model"


# 全局模型管理器
model_manager = ModelManager()
```

### 4.2 三大角色定义

#### 4.2.1 任务节点智能体（TaskNodeAgent）

**数据集背景：Facebook社交网络数据集（SNAP公开）**

- **数据来源**：Stanford SNAP项目提供的Facebook社交网络数据
- **数据规模**：约4,039个节点（用户），88,234条边（双向好友关系）
- **实验设置**：从完整网络中提取子图进行博弈实验（可配置规模，如50-100个核心节点）

**8个任务节点角色定义：**

| 节点编号 | 角色名称 | 任务描述 | 输入 | 输出 |
|---------|---------|---------|------|------|
| Node-1 | 数据采集节点 | 从Facebook网络获取用户基础信息（ID、 profile特征） | 网络拓扑数据 | 用户画像数据 |
| Node-2 | 关系解析节点 | 分析好友关系的双向性、亲密度、互动频率 | 边列表 | 关系强度矩阵 |
| Node-3 | 社区发现节点 | 识别社交圈/社区结构（基于Louvain算法） | 关系数据 | 社区划分结果 |
| Node-4 | 中心性分析节点 | 计算各用户的度中心性、介数中心性、PageRank | 社区结构 | 用户影响力排名 |
| Node-5 | 传播模型节点 | 模拟信息在社交网络中的传播过程（SI/SIR模型） | 网络拓扑+种子节点 | 传播范围统计 |
| Node-6 | 异常检测节点 | 识别异常用户/可疑关系（欺诈账号、水军等） | 用户特征+关系数据 | 风险用户列表 |
| Node-7 | 聚类分析节点 | 对用户进行K-means/层次聚类，细分用户群体 | 用户特征向量 | 用户分群结果 |
| Node-8 | 结果汇总节点 | 汇总各节点分析结果，生成最终社交网络分析报告 | 各节点输出 | 完整分析报告 |

**任务协作流程：**

```
Node-1 数据采集 → Node-2 关系解析 → Node-3 社区发现
                                        ↓
Node-8 结果汇总 ← Node-7 聚类分析 ← Node-6 异常检测
       ↑
Node-4 中心性分析 ←─────────←───────── Node-5 传播模型
```

**节点属性定义：**

```
数量：8个（固定）
作用：构成数据分析流水线，协同完成Facebook网络分析任务
属性：
  - node_id: 节点唯一标识（如"Node-1"）
  - role_name: 角色名称（如"数据采集节点"）
  - neighbors: 依赖的上游/下游节点列表
  - status: 存活/失效状态
  - task_queue: 待处理数据队列
  - processed_data: 已处理的数据缓存
  - capability: 数据处理能力（每秒处理数据量）
```

**节点失效影响：**
- 任一节点失效 → 该节点负责的分析步骤无法完成
- 下游节点缺少输入 → 任务流水线中断
- 连续N轮中断 → 判定为"分析任务失败"

#### 4.2.2 攻击智能体（AttackerAgent）

```
目标：自适应破坏网络关键链路/节点
能力限制：每轮最多切断2条链路
决策流程：
  1. 分析当前网络状态
  2. 计算各链路/节点攻击价值
  3. 选择最优攻击目标
  4. 执行攻击并记录效果
策略演进：基于历史攻击效果调整策略
```

#### 4.2.3 防御智能体（DefenderAgent）

```
目标：修复受损链路，保护网络完整性
能力限制：每轮最多修复2条链路 + 新增1条链路
决策流程：
  1. 扫描网络受损状态
  2. 识别关键链路/节点
  3. 制定修复/加固策略
  4. 执行防御操作
策略演进：基于攻击模式优化防御
```

### 4.3 博弈规则

| 规则项 | 内容 |
|--------|------|
| 初始状态 | 网络全连通，所有节点正常工作 |
| 轮次结构 | 攻击 → 状态检测 → 防御 → 学习更新 |
| 攻击限制 | 每轮最多切断2条链路 |
| 防御限制 | 每轮最多修复2条 + 新增1条 |
| 胜利条件 | 攻击方：连续N轮网络瘫痪；防御方：达到最大轮次网络仍运行 |
| 最大轮次 | 默认30轮（可配置） |

"""
Facebook社交网络数据加载器
数据来源：SNAP Stanford
下载地址：https://snap.stanford.edu/data/ego-Facebook.html
"""

import networkx as nx
from typing import Tuple, Optional
import os


class FacebookDataLoader:
    """Facebook社交网络数据加载器"""
    
    DATA_URL = "https://snap.stanford.edu/data/facebook_combined.txt.gz"
    
    def __init__(self, data_dir: str = "data/raw"):
        self.data_dir = data_dir
        self.data_file = os.path.join(data_dir, "facebook_combined.txt")
    
    def load_full_network(self) -> nx.Graph:
        """
        加载完整Facebook网络
        
        Returns:
            NetworkX Graph对象
            - 节点：Facebook用户ID
            - 边：双向好友关系
        """
        if not os.path.exists(self.data_file):
            self._download_data()
        
        # 读取边列表，构建无向图
        G = nx.read_edgelist(
            self.data_file,
            comments='#',
            delimiter=' ',
            create_using=nx.Graph(),
            nodetype=int
        )
        
        print(f"加载完成：{G.number_of_nodes()} 个节点，{G.number_of_edges()} 条边")
        return G
    
    def load_subgraph(
        self,
        G: nx.Graph,
        center_node: Optional[int] = None,
        num_nodes: int = 100,
        radius: int = 2
    ) -> nx.Graph:
        """
        提取核心子图用于博弈实验
        
        Args:
            G: 完整网络
            center_node: 中心节点（默认选择度数最高的节点）
            num_nodes: 目标节点数
            radius: 扩展半径（从中心节点出发）
            
        Returns:
            子图
        """
        if center_node is None:
            # 自动选择度数最高的节点作为中心
            degrees = dict(G.degree())
            center_node = max(degrees, key=degrees.get)
        
        # 收集半径内的节点
        nodes_in_radius = {center_node}
        current_frontier = {center_node}
        
        for _ in range(radius):
            next_frontier = set()
            for node in current_frontier:
                next_frontier.update(G.neighbors(node))
            nodes_in_radius.update(next_frontier)
            current_frontier = next_frontier - nodes_in_radius
            
            if len(nodes_in_radius) >= num_nodes:
                break
        
        # 如果还不够，随机补充
        if len(nodes_in_radius) < num_nodes:
            remaining = set(G.nodes()) - nodes_in_radius
            additional = set(random.sample(list(remaining), 
                                          min(num_nodes - len(nodes_in_radius), len(remaining))))
            nodes_in_radius.update(additional)
        
        # 构建子图并确保连通
        subgraph = G.subgraph(list(nodes_in_radius)[:num_nodes])
        
        # 如果子图不连通，提取最大连通分量
        if not nx.is_connected(subgraph):
            largest_cc = max(nx.connected_components(subgraph), key=len)
            subgraph = subgraph.subgraph(largest_cc).copy()
        
        print(f"子图提取：{subgraph.number_of_nodes()} 个节点，{subgraph.number_of_edges()} 条边")
        return subgraph
    
    def _download_data(self):
        """下载数据集"""
        import urllib.request
        
        os.makedirs(self.data_dir, exist_ok=True)
        gz_file = self.data_file + ".gz"
        
        print(f"正在下载数据集...")
        urllib.request.urlretrieve(self.DATA_URL, gz_file)
        
        import gzip
        with gzip.open(gz_file, 'rb') as f_in:
            with open(self.data_file, 'wb') as f_out:
                f_out.write(f_in.read())
        
        os.remove(gz_file)
        print("下载完成")


# 数据统计信息
def get_network_statistics(G: nx.Graph) -> dict:
    """计算网络统计指标"""
    return {
        "节点数": G.number_of_nodes(),
        "边数": G.number_of_edges(),
        "平均度": sum(dict(G.degree()).values()) / G.number_of_nodes(),
        "网络密度": nx.density(G),
        "聚类系数": nx.average_clustering(G),
        "是否连通": nx.is_connected(G),
        "连通分量数": nx.number_connected_components(G),
        "最大连通分量大小": len(max(nx.connected_components(G), key=len)) if not nx.is_connected(G) else G.number_of_nodes()
    }

```python
"""
网络管理器
负责网络的构建、修改、状态维护
"""

import networkx as nx
import random
from typing import List, Tuple, Dict, Optional, Set
from dataclasses import dataclass, field
import json


@dataclass
class NetworkState:
    """网络状态快照"""
    round_num: int
    nodes: Dict[str, bool]                    # 节点存活状态
    edges: List[Tuple[str, str]]              # 当前活跃链路
    largest_cc_size: int                       # 最大连通分量大小
    avg_shortest_path: float                  # 平均最短路径
    clustering_coeff: float                   # 聚类系数
    attack_history: List[Dict] = field(default_factory=list)
    defense_history: List[Dict] = field(default_factory=list)


class NetworkManager:
    """网络管理器"""
    
    def __init__(self, num_nodes: int = 8, avg_degree: float = 3.0, seed: int = 42):
        """
        初始化网络管理器
        
        Args:
            num_nodes: 节点数量
            avg_degree: 平均度数
            seed: 随机种子
        """
        self.num_nodes = num_nodes
        self.avg_degree = avg_degree
        self.seed = seed
        self.round_num = 0
        
        # 构建初始网络
        self.graph = self._build_initial_network()
        self.initial_edges = list(self.graph.edges())
        
        # 历史记录
        self.state_history: List[NetworkState] = []
        
        # 节点属性
        self.node_capabilities = {node: random.randint(1, 5) for node in self.graph.nodes()}
    
    def _build_initial_network(self) -> nx.Graph:
        """构建初始网络（随机几何图，兼顾小世界特性）"""
        random.seed(self.seed)
        
        # 方法1：Watts-Strogatz小世界网络（推荐）
        # 兼具高聚类和短路径特性，更接近真实网络
        G = nx.watts_strogatz_graph(
            n=self.num_nodes,
            k=int(self.avg_degree),  # 每个节点的近邻数
            p=0.1,                    # 重连概率
            seed=self.seed
        )
        
        # 确保网络连通
        if not nx.is_connected(G):
            # 添加边连通各分量
            components = list(nx.connected_components(G))
            for i in range(len(components) - 1):
                G.add_edge(
                    random.choice(list(components[i])),
                    random.choice(list(components[i + 1]))
                )
        
        return G
    
    def get_active_nodes(self) -> List[str]:
        """获取活跃节点列表"""
        return [str(n) for n in self.graph.nodes()]
    
    def get_active_edges(self) -> List[Tuple[str, str]]:
        """获取活跃链路列表"""
        return [(str(u), str(v)) for u, v in self.graph.edges()]
    
    def get_network_info(self) -> Dict:
        """获取网络基本信息"""
        return {
            "num_nodes": self.graph.number_of_nodes(),
            "num_edges": self.graph.number_of_edges(),
            "is_connected": nx.is_connected(self.graph),
            "num_components": nx.number_connected_components(self.graph),
            "largest_cc_size": len(max(nx.connected_components(self.graph), key=len))
        }
    
    def remove_edge(self, u: str, v: str) -> bool:
        """
        移除链路
        
        Args:
            u, v: 链路两端节点
            
        Returns:
            是否成功移除
        """
        try:
            u, v = str(u), str(v)
            if self.graph.has_edge(u, v):
                self.graph.remove_edge(u, v)
                return True
        except nx.NetworkXError:
            pass
        return False
    
    def add_edge(self, u: str, v: str) -> bool:
        """
        添加链路
        
        Args:
            u, v: 链路两端节点
            
        Returns:
            是否成功添加
        """
        try:
            u, v = str(u), str(v)
            if not self.graph.has_edge(u, v) and u != v:
                self.graph.add_edge(u, v)
                return True
        except nx.NetworkXError:
            pass
        return False
    
    def is_network_paralyzed(self) -> bool:
        """判断网络是否瘫痪（无最大连通分量或分量过小）"""
        if self.graph.number_of_nodes() == 0:
            return True
        
        largest_cc = max(nx.connected_components(self.graph), key=len)
        # 如果最大连通分量小于节点总数的30%，认为网络瘫痪
        threshold = self.num_nodes * 0.3
        return len(largest_cc) < threshold
    
    def get_critical_edges(self, top_k: int = 5) -> List[Tuple[str, str]]:
        """
        获取关键链路（基于介数中心性）
        
        Returns:
            关键链路列表，按重要性排序
        """
        if self.graph.number_of_edges() == 0:
            return []
        
        betweenness = nx.edge_betweenness_centrality(self.graph)
        sorted_edges = sorted(betweenness.items(), key=lambda x: x[1], reverse=True)
        return [(str(u), str(v)) for (u, v), _ in sorted_edges[:top_k]]
    
    def get_critical_nodes(self, top_k: int = 3) -> List[str]:
        """
        获取关键节点（基于度中心性和介数中心性）
        """
        if self.graph.number_of_nodes() == 0:
            return []
        
        # 综合考虑度和介数
        degree_cent = nx.degree_centrality(self.graph)
        betweenness = nx.betweenness_centrality(self.graph)
        
        # 归一化后加权求和
        max_degree = max(degree_cent.values()) if degree_cent else 1
        max_between = max(betweenness.values()) if betweenness else 1
        
        scores = {
            node: degree_cent[node] / max_degree + betweenness[node] / max_between
            for node in self.graph.nodes()
        }
        
        sorted_nodes = sorted(scores.items(), key=lambda x: x[1], reverse=True)
        return [str(node) for node, _ in sorted_nodes[:top_k]]
    
    def save_state(self) -> NetworkState:
        """保存当前网络状态"""
        state = NetworkState(
            round_num=self.round_num,
            nodes={str(n): True for n in self.graph.nodes()},
            edges=[(str(u), str(v)) for u, v in self.graph.edges()],
            largest_cc_size=len(max(nx.connected_components(self.graph), key=len)),
            avg_shortest_path=self._calc_avg_shortest_path(),
            clustering_coeff=nx.average_clustering(self.graph)
        )
        self.state_history.append(state)
        return state
    
    def _calc_avg_shortest_path(self) -> float:
        """计算平均最短路径"""
        if self.graph.number_of_nodes() == 0:
            return float('inf')
        
        try:
            if nx.is_connected(self.graph):
                return nx.average_shortest_path_length(self.graph)
            else:
                # 取最大连通分量的平均路径
                largest_cc = max(nx.connected_components(self.graph), key=len)
                subg = self.graph.subgraph(largest_cc)
                return nx.average_shortest_path_length(subg)
        except:
            return float('inf')
    
    def reset(self):
        """重置网络到初始状态"""
        self.graph = self._build_initial_network()
        self.round_num = 0
        self.state_history.clear()
```

"""
智能体基类
基于AgentScope定义智能体的通用属性和方法
"""

from abc import ABC, abstractmethod
from typing import List, Dict, Any, Optional
import logging
from dataclasses import dataclass, field
from datetime import datetime

import agentscope
from agentscope import Agent
from agentscope.message import Msg

from core.model_manager import model_manager, ModelProvider


@dataclass
class AgentMemory:
    """智能体记忆"""
    history: List[Dict] = field(default_factory=list)
    
    def add(self, event_type: str, content: Any, metadata: Optional[Dict] = None):
        """添加记忆"""
        self.history.append({
            "timestamp": datetime.now().isoformat(),
            "type": event_type,
            "content": content,
            "metadata": metadata or {}
        })
    
    def get_recent(self, n: int = 5) -> List[Dict]:
        """获取最近n条记忆"""
        return self.history[-n:]
    
    def get_by_type(self, event_type: str) -> List[Dict]:
        """按类型获取记忆"""
        return [m for m in self.history if m["type"] == event_type]


class BaseGameAgent(Agent, ABC):
    """
    博弈智能体基类
    
    所有攻防智能体都继承此类
    """
    
    def __init__(
        self,
        name: str,
        role_description: str,
        model_provider: Optional[ModelProvider] = None,
        temperature: float = 0.7,
        max_tokens: int = 512,
        **kwargs
    ):
        """
        初始化智能体
        
        Args:
            name: 智能体名称
            role_description: 角色描述（用于prompt）
            model_provider: 使用的模型提供商
            temperature: 温度参数
            max_tokens: 最大生成token数
        """
        self.role_description = role_description
        self.model_provider = model_provider
        self.temperature = temperature
        self.max_tokens = max_tokens
        
        # 记忆系统
        self.memory = AgentMemory()
        
        # 初始化prompt
        system_prompt = self._build_system_prompt()
        
        # 调用父类初始化
        super().__init__(
            name=name,
            sys_prompt=system_prompt,
            model_config={
                "model_provider": model_provider.value if model_provider else "ollama_local",
                "temperature": temperature,
                "max_tokens": max_tokens
            },
            **kwargs
        )
        
        self.logger = logging.getLogger(f"Agent.{name}")
    
    @abstractmethod
    def _build_system_prompt(self) -> str:
        """构建系统提示词（子类实现）"""
        pass
    
    def think(self, context: Dict[str, Any]) -> str:
        """
        智能思考
        
        Args:
            context: 当前上下文（网络状态、历史等）
            
        Returns:
            思考结果
        """
        messages = [
            Msg("system", self.role_description, "assistant"),
            Msg("user", self._format_context(context), "user")
        ]
        
        response = model_manager.chat(
            messages=messages,
            provider=self.model_provider,
            temperature=self.temperature,
            max_tokens=self.max_tokens
        )
        
        return response
    
    @abstractmethod
    def _format_context(self, context: Dict[str, Any]) -> str:
        """格式化上下文信息（子类实现）"""
        pass
    
    def remember(self, event_type: str, content: Any, metadata: Optional[Dict] = None):
        """记录记忆"""
        self.memory.add(event_type, content, metadata)
```

{self._format_edges(context.get('critical_edges', []))}

关键节点：
{', '.join(context.get('critical_nodes', []))}

=== 最近攻击历史 ===
{self._format_history(recent_history)}
"""
        return prompt
    
    def _format_edges(self, edges: List[Tuple]) -> str:
        """格式化链路列表"""
        if not edges:
            return "（无）"
        return "\n".join([f"  - {u} <--> {v}" for u, v in edges[:10]])
    
    def _format_history(self, history: List[Dict]) -> str:
        """格式化历史记录"""
        if not history:
            return "（无历史记录）"
        
        lines = []
        for i, entry in enumerate(history[-5:], 1):
            action = entry.get("action", "")
            targets = entry.get("targets", [])
            effect = entry.get("effect", "未知")
            lines.append(f"{i}. 攻击 {targets}，效果：{effect}")
        return "\n".join(lines)
    
    def decide_attack_targets(
        self,
        network_state: Dict[str, Any],
        use_llm: bool = True
    ) -> List[Tuple[str, str]]:
        """
        决定攻击目标
        
        Args:
            network_state: 当前网络状态
            use_llm: 是否使用大模型决策
            
        Returns:
            攻击目标列表 [(u, v), ...]
        """
        active_edges = network_state.get("edges", [])
        critical_edges = network_state.get("critical_edges", [])
        recent_history = self.memory.get_recent(5)
        
        if not active_edges:
            return []
        
        # 优先攻击关键链路
        priority_targets = []
        for edge in critical_edges:
            if edge in active_edges:
                priority_targets.append(edge)
        
        # 如果关键链路被修复过，增加优先级
        repaired_edges = self._get_recently_repaired_edges()
        for edge in repaired_edges:
            if edge in active_edges and edge not in priority_targets:
                priority_targets.insert(0, edge)
        
        # 限制攻击数量
        num_to_attack = min(self.max_attacks_per_round, len(active_edges))
        
        if use_llm and len(priority_targets) < num_to_attack:
            # 使用大模型补充选择
            context = {
                "network_info": network_state,
                "recent_history": recent_history,
                "critical_edges": critical_edges,
                "priority_targets": priority_targets
            }
            
            response = self.think(context)
            additional_targets = self._parse_llm_response(response, active_edges)
            priority_targets.extend(additional_targets)
        
        # 去重并限制数量
        final_targets = []
        for t in priority_targets:
            if t not in final_targets and len(final_targets) < num_to_attack:
                final_targets.append(t)
        
        # 如果还不够，随机选择
        while len(final_targets) < num_to_attack:
            remaining = [e for e in active_edges if e not in final_targets]
            if not remaining:
                break
            final_targets.append(random.choice(remaining))
        
        return final_targets[:num_to_attack]
    
    def _parse_llm_response(self, response: str, available_edges: List[Tuple]) -> List[Tuple]:
        """解析大模型回复，提取攻击目标"""
        # 简单的JSON解析
        import json
        import re
        
        try:
            # 尝试提取JSON
            json_match = re.search(r'\{[^{}]*"targets"[^{}]*\}', response, re.DOTALL)
            if json_match:
                data = json.loads(json_match.group())
                targets = data.get("targets", [])
                return [tuple(t) for t in targets if tuple(t) in available_edges]
        except:
            pass
        
        return []
    
    def _get_recently_repaired_edges(self) -> List[Tuple[str, str]]:
        """获取最近被修复过的链路"""
        repaired = []
        for entry in self.memory.get_by_type("edge_repaired"):
            edge = entry.get("content", {}).get("edge")
            if edge:
                repaired.append(tuple(edge))
        return repaired
    
    def execute_attack(
        self,
        targets: List[Tuple[str, str]],
        network_manager
    ) -> Dict[str, Any]:
        """
        执行攻击
        
        Args:
            targets: 攻击目标
            network_manager: 网络管理器
            
        Returns:
            攻击结果
        """
        results = {
            "attacked_edges": [],
            "failed_edges": [],
            "effects": []
        }
        
        for u, v in targets:
            success = network_manager.remove_edge(u, v)
            if success:
                results["attacked_edges"].append((u, v))
                self.remember(
                    "edge_attacked",
                    {"edge": (u, v), "round": network_manager.round_num}
                )
            else:
                results["failed_edges"].append((u, v))
        
        # 计算攻击效果
        results["effects"] = self._calculate_effects(
            results["attacked_edges"],
            network_manager
        )
        
        return results
    
    def _calculate_effects(
        self,
        attacked_edges: List[Tuple],
        network_manager
    ) -> Dict[str, float]:
        """计算攻击效果"""
        info = network_manager.get_network_info()
        
        return {
            "edges_removed": len(attacked_edges),
            "components_before": info.get("num_components", 1),
            "largest_cc_size": info.get("largest_cc_size", 0)
        }

        attack_history = context.get("attack_history", [])
        
        prompt = f"""
=== 当前网络状态 ===
- 活跃节点数：{network_info.get('num_nodes', 0)}
- 活跃链路数：{network_info.get('num_edges', 0)}
- 网络是否连通：{network_info.get('is_connected', False)}

=== 当前活跃链路 ===
{self._format_edges(network_info.get('edges', []))}

=== 关键节点 ===
{', '.join(context.get('critical_nodes', []))}

=== 初始链路（可修复）===
{self._format_edges(context.get('initial_edges', []))}

=== 最近攻击记录 ===
{self._format_attacks(attack_history)}

=== 已被修复的链路 ===
{self._format_edges([list(e) for e in self.repaired_edges])}
"""
        return prompt
    
    def _format_edges(self, edges: List) -> str:
        if not edges:
            return "（无）"
        return "\n".join([f"  - {e[0]} <--> {e[1]}" for e in edges[:10]])
    
    def _format_attacks(self, attacks: List[Dict]) -> str:
        if not attacks:
            return "（无）"
        lines = []
        for i, entry in enumerate(attacks[-5:], 1):
            targets = entry.get("targets", [])
            round_num = entry.get("round", "?")
            lines.append(f"{i}. 第{round_num}轮攻击：{targets}")
        return "\n".join(lines)
    
    def decide_defense_actions(
        self,
        network_state: Dict[str, Any],
        initial_edges: List[Tuple],
        use_llm: bool = True
    ) -> Dict[str, List[Tuple[str, str]]]:
        """
        决定防御动作
        
        Returns:
            {"repairs": [...], "new_edges": [...]}
        """
        active_edges = set(network_state.get("edges", []))
        critical_nodes = network_state.get("critical_nodes", [])
        attack_history = self.memory.get_recent(10)
        
        actions = {"repairs": [], "new_edges": []}
        
        # 1. 修复被攻击过的初始链路
        edges_to_repair = []
        for edge in initial_edges:
            if edge not in active_edges and len(actions["repairs"]) < self.max_repairs_per_round:
                edges_to_repair.append(edge)
        
        actions["repairs"] = edges_to_repair
        
        # 2. 如果需要增加新链路
        if len(actions["new_edges"]) < self.max_new_edges_per_round:
            new_edges = self._find_new_edge_candidates(
                active_edges,
                critical_nodes,
                network_state.get("nodes", [])
            )
            actions["new_edges"] = new_edges[:self.max_new_edges_per_round]
        
        # 3. 使用大模型优化决策
        if use_llm and (len(actions["repairs"]) < self.max_repairs_per_round or 
                        len(actions["new_edges"]) < self.max_new_edges_per_round):
            context = {
                "network_info": network_state,
                "attack_history": attack_history,
                "critical_nodes": critical_nodes,
                "initial_edges": initial_edges,
                "planned_repairs": actions["repairs"],
                "planned_new_edges": actions["new_edges"]
            }
            
            llm_actions = self._get_llm_suggestions(context, active_edges)
            actions["repairs"].extend(llm_actions.get("repairs", []))
            actions["new_edges"].extend(llm_actions.get("new_edges", []))
        
        # 去重
        actions["repairs"] = list(set(actions["repairs"]))[:self.max_repairs_per_round]
        actions["new_edges"] = list(set(actions["new_edges"]))[:self.max_new_edges_per_round]
        
        return actions
    
    def _find_new_edge_candidates(
        self,
        active_edges: Set,
        critical_nodes: List[str],
        all_nodes: List[str]
    ) -> List[Tuple[str, str]]:
        """寻找可以新增的链路候选"""
        candidates = []
        
        # 策略：为核心节点添加旁路连接
        for node in critical_nodes:
            for other in all_nodes:
                if other != node:
                    edge = (min(node, other), max(node, other))
                    if edge not in active_edges and edge not in candidates:
                        candidates.append(edge)
        
        # 如果还不够，随机选择
        while len(candidates) < self.max_new_edges_per_round:
            u, v = random.sample(all_nodes, 2)
            edge = (min(u, v), max(u, v))
            if edge not in active_edges and edge not in candidates:
                candidates.append(edge)
        
        return candidates[:self.max_new_edges_per_round]
    
    def _get_llm_suggestions(
        self,
        context: Dict,
        active_edges: Set
    ) -> Dict[str, List[Tuple]]:
        """获取大模型建议"""
        response = self.think(context)
        
        import json
        import re
        
        try:
            json_match = re.search(r'\{[^{}]*"repairs"[^{}]*"new_edges"[^{}]*\}', response, re.DOTALL)
            if json_match:
                data = json.loads(json_match.group())
                repairs = [tuple(e) for e in data.get("repairs", []) if tuple(e) in active_edges]
                new_edges = [tuple(e) for e in data.get("new_edges", [])]
                return {"repairs": repairs, "new_edges": new_edges}
        except:
            pass
        
        return {"repairs": [], "new_edges": []}
    
    def execute_defense(
        self,
        actions: Dict[str, List[Tuple[str, str]]],
        network_manager
    ) -> Dict[str, Any]:
        """
        执行防御
        
        Returns:
            防御结果
        """
        results = {
            "repairs": [],
            "new_edges": [],
            "failed_repairs": [],
            "failed_new_edges": []
        }
        
        # 执行修复
        for u, v in actions.get("repairs", []):
            if network_manager.add_edge(u, v):
                results["repairs"].append((u, v))
                self.repaired_edges.add((min(u, v), max(u, v)))
                self.remember(
                    "edge_repaired",
                    {"edge": (u, v), "round": network_manager.round_num}
                )
            else:
                results["failed_repairs"].append((u, v))
        
        # 执行新增链路
        for u, v in actions.get("new_edges", []):
            if network_manager.add_edge(u, v):
                results["new_edges"].append((u, v))
                self.new_edges.append((min(u, v), max(u, v)))
                self.remember(
                    "edge_added",
                    {"edge": (u, v), "round": network_manager.round_num}
                )
            else:
                results["failed_new_edges"].append((u, v))
        
        return results
```

        self.paralysis_count = 0

        self.winner: Optional[str] = None

        运行完整博弈
        
        Returns:
            博弈结果摘要

        self.log("=" * 50)

        self._record_round(is_initial=True)

            self.current_round += 1
            self._run_single_round()

            self._check_termination()

            use_llm=self.use_llm_attacker

        is_paralyzed = self.network.is_network_paralyzed()

            use_llm=self.use_llm_defender

        self.log(f"    新增链路: {defense_result['new_edges']}")

            attack_targets=attack_result['attacked_edges'],

"""
网络鲁棒性指标计算
"""

import networkx as nx
import numpy as np
from typing import Dict, Any

from core.network_manager import NetworkManager


class RobustnessMetrics:
    """网络鲁棒性指标计算器"""
    
    def __init__(self):
        self.history = []
    
    def calculate(self, network: NetworkManager) -> Dict[str, float]:
        """
        计算当前网络的所有指标
        
        Returns:
            指标字典
        """
        G = network.graph
        
        if G.number_of_nodes() == 0:
            return self._empty_metrics()
        
        metrics = {
            "num_nodes": G.number_of_nodes(),
            "num_edges": G.number_of_edges(),
            "largest_cc_size": self._largest_connected_component_size(G),
            "largest_cc_ratio": self._largest_connected_component_ratio(G, network.num_nodes),
            "avg_degree": self._average_degree(G),
            "degree_variance": self._degree_variance(G),
            "clustering_coeff": self._clustering_coefficient(G),
            "avg_path_length": self._average_shortest_path(G),
            "diameter": self._network_diameter(G),
            "degree_centralization": self._degree_centralization(G),
            "betweenness_centralization": self._betweenness_centralization(G),
            "efficiency": self._network_efficiency(G),
            "robustness_index": self._robustness_index(G, network.num_nodes)
        }
        
        self.history.append(metrics)
        return metrics
    
    def _empty_metrics(self) -> Dict[str, float]:
        """空网络指标"""
        return {
            "num_nodes": 0,
            "num_edges": 0,
            "largest_cc_size": 0,
            "largest_cc_ratio": 0,
            "avg_degree": 0,
            "degree_variance": 0,
            "clustering_coeff": 0,
            "avg_path_length": float('inf'),
            "diameter": 0,
            "degree_centralization": 0,
            "betweenness_centralization": 0,
            "efficiency": 0,
            "robustness_index": 0
        }
    
    def _largest_connected_component_size(self, G: nx.Graph) -> int:
        """最大连通分量大小"""
        if G.number_of_nodes() == 0:
            return 0
        if not nx.is_connected(G):
            return len(max(nx.connected_components(G), key=len))
        return G.number_of_nodes()
    
    def _largest_connected_component_ratio(self, G: nx.Graph, total_nodes: int) -> float:
        """最大连通分量占比"""
        if total_nodes == 0:
            return 0
        return self._largest_connected_component_size(G) / total_nodes
    
    def _average_degree(self, G: nx.Graph) -> float:
        """平均度数"""
        if G.number_of_nodes() == 0:
            return 0
        return sum(dict(G.degree()).values()) / G.number_of_nodes()
    
    def _degree_variance(self, G: nx.Graph) -> float:
        """度数方差"""
        degrees = [d for n, d in G.degree()]
        if len(degrees) == 0:
            return 0
        return np.var(degrees)
    
    def _clustering_coefficient(self, G: nx.Graph) -> float:
        """聚类系数"""
        if G.number_of_nodes() < 3:
            return 0
        return nx.average_clustering(G)
    
    def _average_shortest_path(self, G: nx.Graph) -> float:
        """平均最短路径"""
        if G.number_of_nodes() < 2:
            return 0
        try:
            if nx.is_connected(G):
                return nx.average_shortest_path_length(G)
            else:
                # 使用最大连通分量
                largest_cc = max(nx.connected_components(G), key=len)
                subg = G.subgraph(largest_cc)
                if subg.number_of_nodes() > 1:
                    return nx.average_shortest_path_length(subg)
                return float('inf')
        except:
            return float('inf')
    
    def _network_diameter(self, G: nx.Graph) -> float:
        """网络直径"""
        if G.number_of_nodes() < 2:
            return 0
        try:
            if nx.is_connected(G):
                return nx.diameter(G)
            else:
                largest_cc = max(nx.connected_components(G), key=len)
                subg = G.subgraph(largest_cc)
                return nx.diameter(subg)
        except:
            return float('inf')
    
    def _degree_centralization(self, G: nx.Graph) -> float:
        """度中心化"""
        if G.number_of_nodes() <= 2:
            return 0
        degree_cent = nx.degree_centrality(G)
        max_degree = max(degree_cent.values())
        n = G.number_of_nodes()
        theoretical_max = (n - 1) * (n - 2) / (n - 1)
        if theoretical_max == 0:
            return 0
        return sum(max_degree - d for d in degree_cent.values()) / theoretical_max
    
    def _betweenness_centralization(self, G: nx.Graph) -> float:
        """介数中心化"""
        if G.number_of_nodes() <= 2:
            return 0
        betweenness = nx.betweenness_centrality(G)
        max_between = max(betweenness.values())
        n = G.number_of_nodes()
        theoretical_max = (n - 1) * (n - 2) / 2
        if theoretical_max == 0:
            return 0
        return sum(max_between - b for b in betweenness.values()) / theoretical_max
    
    def _network_efficiency(self, G: nx.Graph) -> float:
        """网络效率"""
        if G.number_of_nodes() < 2:
            return 0
        return nx.global_efficiency(G)
    
    def _robustness_index(self, G: nx.Graph, original_size: int) -> float:
        """
        综合鲁棒性指数
        综合考虑连通性、效率和结构完整性
        """
        if original_size == 0:
            return 0
        
        cc_ratio = self._largest_connected_component_ratio(G, original_size)
        efficiency = self._network_efficiency(G)
        clustering = self._clustering_coefficient(G)
        
        # 加权综合
        robustness = 0.5 * cc_ratio + 0.3 * efficiency + 0.2 * clustering
        return robustness

## 六、网络鲁棒性指标体系

### 6.1 核心指标定义

| 指标名称 | 计算公式 | 含义 | 取值范围 |
|---------|---------|------|---------|
| 最大连通分量比例 | largest_cc_size / N | 网络连通程度 | 0~1 |
| 平均最短路径 | Σd(i,j) / N(N-1) | 传输效率 | 1~∞ |
| 聚类系数 | 3×三角形数 / 三角形的数目 | 局部聚集程度 | 0~1 |
| 网络效率 | 1 / 平均最短路径 | 整体传输效率 | 0~1 |
| 鲁棒性指数 | 加权综合指标 | 综合抗毁能力 | 0~1 |

### 6.2 指标采集时机

- **实验开始前**：记录初始网络各指标
- **每轮攻击后**：记录攻击后指标
- **每轮防御后**：记录防御后指标

### 7.2 对照组实现

**对照组1：随机攻击策略**

```python
class RandomAttacker:
    """随机攻击策略（传统随机攻击）"""
    
    def __init__(self, max_attacks: int = 2):
        self.max_attacks = max_attacks
    
    def select_targets(self, network: NetworkManager) -> List[Tuple]:
        edges = network.get_active_edges()
        return random.sample(edges, min(self.max_attacks, len(edges)))
```

**对照组2：度数攻击策略**

```python
class DegreeAttacker:
    """度数攻击策略（传统蓄意攻击）"""
    
    def __init__(self, max_attacks: int = 2):
        self.max_attacks = max_attacks
    
    def select_targets(self, network: NetworkManager) -> List[Tuple]:
        # 选择度数最高的节点相连的边
        degree_dict = dict(network.graph.degree())
        sorted_nodes = sorted(degree_dict.keys(), key=lambda x: degree_dict[x], reverse=True)
        
        targets = []
        for node in sorted_nodes[:5]:
            for neighbor in network.graph.neighbors(node):
                edge = (min(node, neighbor), max(node, neighbor))
                if edge not in targets:
                    targets.append(edge)
                    if len(targets) >= self.max_attacks:
                        return targets
        
        return targets
```
